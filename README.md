# calculator-js
****************
Обычный калькулятор, который сделан на JavaScript
****************
Для запуска:
1. cd my-calculator
2. npm install
3. npm run dev
Если TailWind не работает, то пропишите rm -rf node_modules, потом npm install и запустить локал npm run dev.
